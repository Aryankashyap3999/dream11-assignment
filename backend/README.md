# MatchPulse backend

Express 5 + TypeScript + Prisma 8 ORM on PostgreSQL. Setup, environment variables, API overview, tests and deployment are documented in the [root README](../README.md).

Scripts (`package.json`): `dev`, `build`, `start`, `test`, `db:seed`, `eval:ai`, `contract:emit`. The schema is created with `npx prisma db init` (not an npm script). Provider-specific Prisma reference docs are in `prisma-8.md`.
